# PhysiCell 1.14.2 template project

`main.cpp`, `Makefile`, `custom_modules/` and `config/PhysiCell_settings.xml` are copied unchanged from
PhysiCell 1.14.2 (`sample_projects/template`). ABMfact exports ABM-IR models onto this project: it
writes new files into `config/` and builds the C++ here unchanged. PhysiCell is distributed under the
